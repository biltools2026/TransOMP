OMPpredictor is algorithms for OMP prediction, including OMP identification and transmembrane region location. 

Download link
https://pan.baidu.com/s/1IwsqQBPW_bUbmtCzp2wqmA?pwd=1234
code: 1234

Currently, the program can only be run in Windows systems.

Performance
The model was trained on a data set consisting of structurally known OMPs.
And the accuracy of the model exceeds 80%.

Install
You should install Perl and Java before you running the program.
Meanwhile, the path of java program ($jpath) in the omprun.pl script 
should be changed according to the installed Java in your computer.

Running example:

First, you should enter the directory of the program and run
perl omprun.pl -omp E:\Udisk128\projects\OMPpredictor\1A0S\seq.fasta

Output is as below:
The protein is probably OMP using library 1

Max score with non-OMP library=0.6797235

The protein is probably OMP using library 2
Max score with OMP     library=0.7841584
Max score with non-OMP library=0.6694813

If both results of two libraries are predicted as OMP, the protein are very likely to be an OMP
